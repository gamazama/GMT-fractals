# GMT 0.9.8.1 — Audio modulation

Released [unreleased — pending push]. 45 commits since 0.9.8 (2026-07-12).
User-facing notes; the engineering log lives in git history and the ADRs
(0103 update, 0104–0110).

## The spectrum finally reads like music

The analyser used to work on raw FFT bins, which are evenly spaced in Hz. Music
is not: at the default settings the entire kick octave (40–80 Hz) got three
bins while the top octave got 683. Picking a kick band meant dragging a
hairline, and a narrow sound got diluted by the wide band around it.

- **Fractional-octave bands.** Every band is now the same *musical* width, so
  the bass gets as many bands as the treble and a band means the same thing
  wherever it sits. Choose 1/3, 1/6 or 1/12 octave.
- **Bands are selected in real Hz**, not as a percentage of the spectrum. A
  kick band is 40–120 Hz and says so, on any device.
- **Tilt** lifts the high bands to offset music's natural roll-off, so hi-hats
  and air read as strongly as a kick without flattening anything. It is a fixed
  offset, so it costs no dynamics.
- **Honest resolution limits.** Bands too narrow for the current Detail setting
  are drawn dimmed rather than silently reporting their neighbours.

## Reacting to hits, not just loudness

- **Transient mode** on any link: the parameter punches on each hit and falls
  back between them, instead of lagging the attack and holding through the
  sustain. It uses onset detection that ignores a note merely sliding in pitch,
  so vibrato and filter sweeps stop reading as a continuous hit.
- **Auto Gain** tracks the input level so one set of thresholds keeps working
  when the DJ changes track, without ramping up through the gaps.

## Live input that survives a venue

- **Device picker** for mic, line-in and system audio, with the running device
  remembered and the list refreshing when you plug an interface in mid-set.
- **Input trim and a level meter**, with clear warnings when the signal is
  clipping or too quiet to gate.
- **Browser processing is now explicitly off.** Chrome enables echo
  cancellation, noise suppression and auto-gain by default, which duck, notch
  and pump a line feed from a desk — indistinguishable from "the audio
  modulation is broken". They are disabled on every capture.

## Analysis moved off the interface thread

Audio is now analysed on the browser's dedicated audio thread. It keeps running
at full rate while the interface is busy — compiling a shader, loading a scene,
anything that used to make the spectrum freeze and drop whole seconds of hits.

- **Response and Detail no longer fight each other.** Detail sets frequency
  resolution, Response sets speed, and raising one no longer slows the other.
- **Roughly 40% less lag** end to end at the default settings, and the response
  you dial in no longer changes with frame rate.

## Scenes remember their modulations

- **Saved scenes now restore their audio links.** Loading a scene brings back
  the modulation that was saved with it — while your *input* stays connected,
  so you are not re-patching a mic between looks.
- **Modulation recording captures every frame.** A recording taken while the
  interface was busy used to flatten whole stretches into a single held value;
  each frame now gets the audio that actually played at that moment.

## Modulation reaches more of the scene

- **Rotation, camera and lighting modulate live**, not only in rendered output.
- **Curved parameters respond evenly.** On around 23 parameters a link used to
  move the value up to 130× more at one end of its range than the other — light
  intensity and falloff worst of all, which made them feel dead at high values.
- **Vector parameters show the live indicator**, so you can see which axes are
  being driven.

## Panel

Rebuilt around what you actually watch: the spectrum and the links stay in
view, with input, decks and analysis settings tucked into collapsible sections.
The panel no longer disappears when you switch audio off — which used to hide
the control that switches it back on.
