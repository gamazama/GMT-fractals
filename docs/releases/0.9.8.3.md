# GMT 0.9.8.3 — Repairs, and a new Gradient Explorer

Released September 9, 2026. 131 commits since 0.9.8.2 (2026-09-01).
User-facing notes; the engineering log is in [`docs/CHANGELOG_DEV.md`](../CHANGELOG_DEV.md)
and the ADRs.

Two halves. The first is the rest of the codebase audit landing as real fixes —
including one that changes how some saved scenes look, so read that first. The
second is a rebuilt Gradient Explorer, online as a preview at its own address.

## Modular scenes — please read if you use the node graph

- **Five nodes were corrupting every node placed after them.** Scale, Twist,
  Bend, Smooth Union and Mix each read one of their own settings twice, and each
  extra read consumed a slot the graph never filled. The result: the node read
  its neighbour's value, and everything downstream shifted along with it. A
  Scale placed in front of a Mandelbulb made the bulb read a power of 0.1
  instead of 8 — a blank or formless render — and dragging the Power slider
  moved the phase instead.

  This is fixed, and **saved Modular scenes containing any of those five nodes
  will render differently now**: they read the values their sliders actually
  show. If you tuned a scene around the old behaviour, it will have moved.

- **The Auto Compile checkbox is gone.** It threw an error the moment you
  clicked it, and nothing behind it was ever implemented — so nothing ever
  auto-compiled, and the COMPILE button pulsed permanently whether or not there
  was anything to compile. COMPILE is the workflow, and it now lights up only
  when the graph would actually build a different shader.
- **Deleting a connection, or swapping which shape feeds a boolean, now counts
  as a change.** Both used to leave COMPILE looking satisfied while the picture
  was stale, so the edit appeared to do nothing.

## Formula Workshop

- **Preview and Import worked for formulas the standard importer cannot read.**
  Two of the shipped library formulas fall into that case, and for them both
  buttons did precisely nothing — no import, no error, no message. They work
  now, and you can name the import before it lands.
- **21 shipped formulas are no longer hidden.** They were filed as "renders
  under neither pipeline" by a catalog snapshot taken in April; all 21 load
  today. They are shown greyed rather than hidden, with "show broken" to enable
  them, so you can see what is there and judge for yourself.

## Things that were quietly broken

- **A crash while drawing the interface now shows a page, not a white screen.**
  Any error while rendering the UI used to take the whole app down with no
  message and no way back except a reload you had to guess at. You now get the
  error, and a Reload button.
- **A shader that fails to compile now says so.** Before, a failed compile left
  the renderer producing empty frames indefinitely with nothing on screen to
  explain it. There is now a red notice carrying the actual error, which clears
  itself on the next successful compile.
- **An export frame that stalls now fails and reports.** If the renderer went
  quiet mid-frame the export dialog waited forever. It now gives up after a
  minute of no progress from the renderer — and only on *no progress*, so a
  legitimately slow 4K path-traced frame is never cut short.
- **Audio modulation dropped a whole ring of onsets** at one exact timing
  coincidence, so beats occasionally went missing for no visible reason.
- **One broken overlay could freeze the entire renderer.** A single failing
  element would stop every other per-frame job and the worker along with it,
  which looked like the renderer hanging rather than one thing being wrong. The
  rest of the frame now carries on and the failure is named in the console.
- **A saved camera renamed to nothing now cancels** instead of storing a blank
  name, and names no longer keep stray spaces.

## Performance

- **Less of the audio path now competes with the renderer for the graphics
  card.** With audio running, the interface was repainting itself sixty times a
  second — every open panel, on the same GPU the fractal renders on. That is
  down to twenty, the spectrum display no longer draws on the graphics card at
  all, and it stops entirely when scrolled out of view.

  **This is an improvement, not a cure.** Enabling audio still costs frame rate,
  and finding the rest of it needs proper profiling rather than reasoning about
  the code — that work is scheduled.

## New: Gradient Explorer v2 (preview)

A ground-up rebuild of the gradient tool, online now at
<https://app.gmt-fractals.com/gradient-explorer-next.html>. It is **not yet
linked to GMT** — nothing in the fractal app hands a gradient to it or takes one
back — and the old Gradient Explorer is untouched at its usual address. This is
there to be looked at and used on its own.

- **One gradient, seen twice.** The palette and the stop editor are the same
  object: edit either and the other follows.
- **A wall of gradients you can browse, search and filter**, with "More like
  this" ranking by how close the colours actually look rather than by their
  numbers, and a pad that maps where you are in the wall.
- **Sets on one ground** — Recent files itself into dated bins, and any narrowed
  search can be kept as a set of its own.
- **Working faces under the gradient**: Mix two gradients, pull one out of an
  image (with a colour cloud you can pick clusters from), reshape it with
  Curves, or Adjust it — each previewing live, each with one bake or cancel.
- **A new colour picker**, shared with GMT: a spectrum or a colour wheel with
  draggable harmony handles, real sliders with right-click reset and precision
  dragging, Kelvin with a tint axis, and recent colours to hand.
- **Wallpaper mode** — the gradient as a full-screen field with its own
  on-screen controls: linear, radial, conic, spline, gradient map and fractal.
  Live frames now render on the graphics card, which took a moving frame from
  around 130 ms to under 2 ms at 2560×1440, while the settled image still gets
  the higher-quality dither it always had.

  Liquify is marked "wip" in the mode list and is genuinely unfinished.

Phone layout, and the swap that would retire the old Gradient Explorer, are
still to come.
